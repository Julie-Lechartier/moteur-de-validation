# MOTEUR DE VALIDATION

## Description
Application React de formulaire avec validation côté client.  
Permet de saisir des informations personnelles (nom, prénom, email, date de naissance, code postal, ville) avec contrôle en temps réel et affichage des erreurs.

## Prérequis
- Node.js >= 20.x
- npm >= 9.x

## Installation
1. Cloner le dépôt :
```bash
git clone https://github.com/ton-utilisateur/ton-depot.git
cd my-app
```

2. Installer les dépendances:

```
npm install 
```
3. Lancer l'application:

```
npm start
```
L'application sera accessible sur http://localhost:3000
